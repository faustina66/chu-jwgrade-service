# JWGrade

长安大学成绩自动监控工具。

它会定时检查教务系统成绩页面，发现成绩更新后，通过 PushPlus 推送到微信。

> 当前版本：`0.1.0-alpha.1`，适合个人自部署使用。

## 长什么样

![推送效果示例](docs/push-example.png)

左边是正常出分，右边是挂科——分数、绩点和各项明细都会标红。
图里的数据是虚构的，用 `tools/demo_push.py` 生成，不含任何真实成绩。

嫌明细太多可以把 `notify.detail_level` 改成 `brief`，
那样只推课程名和最终成绩——PushPlus 的服务器也就只能看到这些。

## 功能

- 自动检查成绩更新；
- 支持新增、变更、撤回和重新发布；
- 成绩变化推送到微信；
- 保存成绩快照和变更历史；
- 推送失败后自动补发；
- 复用登录会话，减少重复登录；
- 支持 Linux 常驻运行。

## 开始使用

这是一个需要自行部署的 Linux 服务，跑在你自己的服务器上，用你自己的账号。

**需要 Python 3.10+**——Ubuntu 22.04 及以上或 Debian 12 及以上都自带，Ubuntu 20.04（3.8）和 Debian 11（3.9）不行。

第一次部署请完整阅读 **[`docs/deployment.md`](docs/deployment.md)**，README 不重复展开部署命令。

装好之后的日常使用——看状态、改轮询频率、改了教务密码怎么办、怎么停、怎么换服务器——看 **[`docs/operations.md`](docs/operations.md)**。

## 注意事项

- 这是个人自用工具，不要把他人的学号、密码或 Cookie 交给公共服务器；
- 不要把 `config.yaml`、`data/`、日志、Cookie、成绩快照或 PushPlus token 上传到 GitHub；
- 不要为了检查状态反复重启服务，首次部署脚本会访问真实认证系统；
- 学校教务系统页面或访问方式变化后，程序可能需要维护。
